# ArthurCRM — краткая инструкция по запуску и безопасности

Коротко:
- Приложение: Next.js (pages), используется Supabase для auth и БД.
- Развёртывание: Vercel (vercel.json присутствует).

Быстрый старт (локально):
1. Клонируйте репозиторий и установите зависимости:
   ```bash
   npm install
   ```
2. Создайте файл `.env.local` на основе `.env.example` и заполните значения.
3. Запустите в режиме разработки:
   ```bash
   npm run dev
   ```

Обязательные переменные окружения (см. `.env.example`):
- NEXT_PUBLIC_SUPABASE_URL
- NEXT_PUBLIC_SUPABASE_ANON_KEY
- SUPABASE_SERVICE_ROLE_KEY  (должен быть доступен только на сервере, не в клиентском коде)
- NEXT_PUBLIC_APP_URL
- CRM_HANDOFF_SECRET
- YOOKASSA_SHOP_ID, YOOKASSA_SECRET

Безопасность и операции с БД:
- SUPABASE_SERVICE_ROLE_KEY полностью обходят RLS: проверяйте авторизацию и входные данные в каждом API-роуте перед использованием этого ключа.
- Критические операции (переводы, покупки) должны выполняться атомарно на стороне БД через RPC или транзакции (SELECT FOR UPDATE / UPDATE ... RETURNING), чтобы избежать гонок.
